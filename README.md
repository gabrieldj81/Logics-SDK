# Logic's SDK
A Premade Toolbox of C# Classes to make developing games in Unity 6.3+ easier

# Roadmap
- [X] 3D Code Separation
- [ ] 2D Code Separation
- [ ] VR Code Separation (Stored in a separate package)
- [ ] Burst Compiler Support
- [ ] ECS Variants/Support (Stored in a separate package)
- [ ] AI Code (Stored in a separate package)

# Documentation
I haven't got to making the documentation yet. So just go off of the code for now.
What I will tell you is to go to your package manager, press the +, press "Add from git URL", and paste "https://github.com/gabrieldj81/Logics-SDK.git"
If you want to use the code in your own code, then add "using CakeLogicSDK;" which will work for anything aside from the 3D folder.
Again, the documentation hasn't been written yet.
